# Where's That Stock

Web pública que muestra el stock actual de productos de Pokémon TCG en
Amazon.es, con búsqueda e indicador de última actualización.

`products.json` se genera y sube automáticamente desde el workflow del
[pokestock-tcg-bot](https://github.com/enkairito/pokestock-tcg-bot) tras cada
comprobación de stock. No editar a mano.

Servida gratis con GitHub Pages.
